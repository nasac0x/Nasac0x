## 🚀 Projects

### 💎 [Nivra](https://github.com/nasac0x/Nivra)
Personal finance dashboard with AI-powered insights, built around privacy: data stays local, zero telemetry, and you bring your own Gemini key. Modular drag-and-drop dashboard, multi-currency (USD, BRL, EUR), goals, and PDF/XLSX/JSON export, all wrapped in a dark glass UI.
`Next.js` `React` `TypeScript` `Tailwind CSS` `Gemini AI`

### 🦎 [video-to-svg-animation](https://github.com/nasac0x/video-to-svg-animation)
An agent skill that recreates videos, GIFs or reference animations as lightweight vector (SVG) animations that stay crisp at any size, with no JavaScript required. It traces the key artwork once and re-animates every movement with vectors.
`Python` `SVG` `OpenCV` `GSAP`
